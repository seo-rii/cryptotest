# 2. 암호구현 - 256비트 permutation 복원

## 문제

제공된 `contest.c`에는 256비트 상태 `state256_t`와 네 가지 서브 연산이 구현되어 있다.

- 64-bit word별 rotate
- 256-bit word별 XOR constant
- 8-bit byte shuffle
- 64-bit word별 add constant

하지만 1라운드 permutation의 서브 연산 순서와 rotation 배열 `rot[4]`가 비어 있다. 참가자는 테스트 벡터를 이용해 구조와 파라미터를 복원하고, 20라운드 permutation도 검증해야 한다.

## 배경지식

이 문제는 암호구현에서 자주 나오는 known input/output 기반 black-box 분석 문제다. 각 서브 연산의 성질을 보면 역연산이 쉽다.

- XOR constant: 같은 constant로 다시 XOR하면 복원된다.
- Add constant modulo `2^64`: constant를 빼면 복원된다.
- Byte reverse shuffle: reverse map은 자기 자신의 역함수다.
- Rotate left: `1..63` 후보를 모두 시도하면 바로 찾을 수 있다.

따라서 가능한 연산 순서 24개를 무작정 검사할 수도 있지만, PDF에 제시된 흐름과 코드 주석을 이용하면 훨씬 간단하다. 주석에는 `rotation -> XOR -> shuffling -> add`라고 되어 있고, 테스트 벡터는 이 순서를 확인하는 역할을 한다.

## 풀이

### 1. 연산 순서

`contest.c`의 주석과 테스트 벡터를 대조하면 1라운드는 다음 순서다.

```text
rotate_words_left_64wise
xor_constants_256wise
shuffle_bytes_256
add_constants_64wise
```

문제에서 제공된 `shuffle_map[i] = 31 - i`는 32바이트 전체를 뒤집는 연산이다.

### 2. rotation 값 복원

첫 번째 테스트 벡터를 사용한다. 출력에서 add constant를 먼저 빼고, reverse-byte shuffle을 다시 적용하고, XOR constant를 제거하면 rotate 직후 상태가 나온다.

```text
after_rotate[i] = inverse_xor(inverse_shuffle(output - constants1))[i]
```

각 word에 대해 다음 조건을 만족하는 `r`을 `1..63`에서 찾는다.

```text
rotl64(input[i], r) == after_rotate[i]
```

결과는 다음과 같다.

```c
const unsigned int rot[4] = { 43, 7, 29, 14 };
```

네 값은 모두 `1..63`이고 서로 다르다.

### 3. 20라운드 검증

복원한 1라운드를 20번 반복하면 제공된 `testvector_20round.txt`와 일치한다.

```text
input:
0011223344556677 8899aabbccddeeff 0123456789abcdef fedcba9876543210

output:
7527ddf4dcac1a6c c16754941f41bbba 5f35b110c1dc4504 2d6663801ac4aae8
```

## 구현 패치 요약

`contest.c`에 넣을 핵심 코드는 다음과 같다.

```c
void permute_one_round(...) {
    rotate_words_left_64wise(state, rot);
    xor_constants_256wise(state, constants2);
    shuffle_bytes_256(state, shuffle_map);
    add_constants_64wise(state, constants1);
}
```

20라운드는 루프 내부에서 같은 1라운드를 호출하면 된다.

```c
for (int r = 0; r < 20; r++) {
    permute_one_round(state, rot, shuffle_map, constants2, constants1);
}
```
