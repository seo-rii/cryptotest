# 7. 소인수분해 - RSA 부분 비트 유출

## 문제

2048비트 RSA 공개키 `N = pq`, 공개 지수 `e = 65537`, 암호문 `ct`가 주어진다. 1024비트 소수 `p`에 대해서는 `MASK`와 `p & MASK`도 공개된다. `MASK`의 비트가 1인 위치에서는 `p`의 해당 비트를 알 수 있다.

목표는 유출된 비트를 이용해 `p`, `q`를 복원하고 textbook RSA 암호문을 복호화하는 것이다.

## 배경지식

### 부분 키 노출과 작은 근

RSA의 소인수 일부가 충분히 알려지면 미지 부분을 변수로 놓고 다음 나눗셈 조건을 이용할 수 있다.

```text
p(x, y) | N
```

이는 실제 근에서 `p(x, y) = 0 mod p`인 작은 근 문제다. Coppersmith 및 Herrmann--May 계열 공격은 이 합동식을 만족하는 다항식의 배수들을 격자에 넣고 감축하여, 실제 작은 근에서 정수 0이 되는 보조 다항식들을 얻는다.

### 수정된 문제 데이터

최종 PDF의 마스크를 LSB=0 기준으로 파싱하면 1024비트 중 672비트를 알고 352비트를 모른다. 미지 구간은 다음 일곱 개다.

```text
150..153    4 bits
265..348   84 bits
362..419   58 bits
600..668   69 bits
682..768   87 bits
784..829   46 bits
920..923    4 bits
```

초기 문서에 기록됐던 `613 known / 411 unknown`과 `210..248`, `420..439` 구간은 이전 데이터에 대한 분석이므로 최종 풀이에는 사용하지 않는다.

## 풀이

### 1. 직접 탐색과 실패한 전략

미지 비트 352개의 전수조사는 `2^352` 경우라 불가능하다. 아래 접근들도 문제 구조와 안전한 배제 조건을 찾는 데는 도움을 줬지만 최종 인수분해로 이어지지는 않았다.

| 전략 | 관찰된 결과 | 중단한 이유 |
|---|---|---|
| 전체 곱셈 SMT/CP-SAT | `p*q=N`을 직접 넣은 Z3/CVC5 모델은 제한 시간에 답을 내지 못했고, OR-Tools CP-SAT도 `UNKNOWN`이었다. | 2048비트 곱셈의 긴 carry 의존성과 흩어진 352개 미지 비트 때문에 전역 전파가 약했다. |
| 일곱 블록 다변수 Coppersmith/cuso | exact, grouped, mixed 변수 구성을 시험했지만 많은 실행이 유용한 정수 관계를 얻기 전에 `timeout`됐거나 root가 없었다. | 변수와 monomial 수, 격자 차원이 너무 빨리 증가해 실제 크기로 확장하기 어려웠다. |
| q-gap/low600 Coppersmith + SAT/Hensel | 여러 후보 cube에 대한 `sound no-root`와 learned clause는 얻었지만 factor는 나오지 않았고, Hensel 검사는 자주 `SAT`/`UNKNOWN`에 머물렀다. | 고정한 비트가 많은 긴 clause는 일부 branch만 제거해 SAT 탐색을 정답으로 충분히 수렴시키지 못했다. |
| two-sided/partial-`p`, Coron 및 초기 HM 변형 | 작은 파라미터에서는 root가 없었고 파라미터를 키우면 수백 초 `timeout` 또는 과도한 격자 비용이 발생했다. | heuristic no-root나 `timeout`은 안전한 배제 증명으로 쓸 수 없고, 256개 edge 후보 전체를 훑기에는 너무 느렸다. |

여기서 “실패”는 해당 수학적 방법이 원천적으로 적용 불가능하다는 뜻이 아니라, 시험한 변수 분할과 파라미터로는 완결된 root/factor를 얻지 못했다는 뜻이다. 이 실험들이 준 결정적인 방향은 작은 양끝 nibble만 전수조사하고, 나머지는 내부 known bit 제약을 완화한 두 연속 변수로 합치는 것이었다.

### 2. 256개 edge 후보

양끝의 4비트 구간을 하나의 후보 번호로 묶는다.

```text
low  = p[150..153]
high = p[920..923]
cid  = (high << 4) | low
```

따라서 edge 후보는 `0..255`의 256개뿐이다. 한 후보를 고정한 뒤 `265..419`와 `600..829`를 각각 연속 정수 `x`, `y`로 둔다. 두 블록 안에 이미 알려진 비트도 있지만, 그 제약을 잠시 버리면 변수 수를 크게 줄일 수 있다.

```text
p = C + 2^265*x + 2^600*y
0 <= x < 2^155
0 <= y < 2^230
```

여기서 `C`는 해당 후보의 두 edge nibble과 두 연속 블록 밖의 알려진 비트를 합친 상수다. 알려진 내부 비트 조건을 완화했어도 실제 `p`는 여전히 이 식의 작은 근이므로 공격의 완전성은 잃지 않는다.

### 3. 이변수 Herrmann--May 격자

최종 solver는 `A = 2^265`, `B = 2^600`으로 놓고, `A`의 역원을 곱해 다음처럼 `x`에 대해 monic인 다항식을 만든다.

```text
f(x, y) = x + (B*A^-1 mod N)y + (C*A^-1 mod N)  (mod N)
```

실제 근 `(x0, y0)`에서는 `C + Ax0 + By0 = p`이고 `p | N`이므로 `f(x0, y0) = 0 mod p`다.

`m=17`, `t=5`에서 다음과 같은 triangular shift들을 사용한다.

```text
y^j * f(x,y)^k * N^max(t-k, 0),  k+j <= m
```

전체 차원은 다음과 같다.

```text
(m+1)(m+2)/2 = 18*19/2 = 171
```

계수는 해당 `N` 거듭제곱을 기준으로 중앙 잉여값에 가깝게 바꾸고, monomial `x^i y^j` 열은 `X^i Y^j`로 스케일한다. 여기서 `X=2^155`, `Y=2^230`이다. 이렇게 만든 상삼각 형태의 171차원 격자를 목표 RHF `1.15`로 FLATTER에서 감축했다.

최종 파라미터는 다음과 같다.

```text
m=17, t=5, dimension=171
leading variable=x
centered coefficients=true
target RHF=1.15
```

### 4. 결과식과 CRT로 근 복원

감축된 행 중 L1 norm이 작은 12개를 보조 다항식으로 선택한다. 큰 정수 위에서 한 번에 결과식을 계산하는 대신 약 30비트 소수체에서 다음 과정을 반복한다.

1. 보조 다항식 쌍의 resultant로 `x`를 제거한다.
2. 여러 resultant의 GCD를 구해 `y`에 대한 일차식을 얻는다.
3. `y`를 대입한 보조 다항식들의 GCD로 `x`를 얻는다.
4. 복원한 `(x, y)`가 선택한 모든 보조 다항식을 만족하는지 확인한다.
5. 서로 다른 소수에서 얻은 근을 CRT로 합친다.

오답 edge 후보는 대개 첫 소수 `1,000,000,007`에서 resultant GCD가 1이 되어 빠르게 탈락한다. 정답 후보에서는 8개 소수의 공통근이 일치했고, CRT modulus가 약 240비트가 되어 `Y`를 넘었을 때 정수 근과 `p`가 유일하게 복원됐다.

```text
cid  = 155 = 0x9b
low  = 0xb
high = 0x9
```

### 5. 복원 결과

두 소인수는 다음과 같다.

```text
p = 0xffa360d46885c534d186538179633fafc2c0548a2e24a2c1c878569f522939e38ff75ead1bcd442a834974a52e3ac66c1bc2ee00d63e2de4c436d2ca740a624699e1a1af94045c63261323cb723a7ba1b3c00bbbb6a4e534c11469e73ddbb2e50b0bc2461fcbac0726360c2c0ac9450a9a892cbf1d98ceee48827591ccc593c9
q = 0xe557fa8670389cb60c84416a65742a74fd11ed33b1631f787e92b90887b5391dacba00a386911bf8a8fbd57430b9b26e455329405ffe289e20616fe3b5562ea9b533f8f8db94bb8dcd280a6af056108e176008d3655428ad0ac6396318ba0f6efe496eac3f8585675bfed67081e0c518be5685e4daf7060abe1c58b73cc5f1e9
```

이후 표준 RSA 개인 지수를 계산해 복호화한다.

```python
phi = (p - 1) * (q - 1)
d = pow(65537, -1, phi)
m = pow(ct, d, N)
```

최종 평문은 다음과 같다.

```text
FLAG{d1rty_b1t_l34k_c0pp3rsm1th_m33ts_str4t3gy}
```

## 재현

### 결과 검증과 복호화

저장소 루트에서 다음 명령을 실행한다.

```bash
python3 solutions/solve_07_final.py
```

이 스크립트는 `p*q == N`, mask 일치, RSA 재암호화까지 모두 검사한 뒤 FLAG를 출력한다.

### 격자 공격 재실행

Debian FLINT, GMP, OpenBLAS와 로컬에 설치한 FLATTER가 필요하다.

```bash
g++ -O3 -std=c++17 -I/usr/local/include \
  solutions/solve_07_grouped_hm_flatter.cpp \
  -L/usr/local/lib -Wl,-rpath,/usr/local/lib \
  -lflatter -lflint -lgmpxx -lgmp -lopenblas -pthread \
  -o /tmp/solve_07_grouped_hm_flatter

/tmp/solve_07_grouped_hm_flatter --modular-selftest

OPENBLAS_NUM_THREADS=1 /tmp/solve_07_grouped_hm_flatter \
  --challenge --cid 155 --m 17 --t 5 --rhf 1.15 --lead x --centered
```

마지막 명령은 머신 성능에 따라 수 분 정도 걸릴 수 있으며 `RECOVERED p=...`를 출력한다. 256개 후보 전체를 조사할 때는 `--cid`만 바꾸어 병렬 실행할 수 있다.

## 검증

최종 결과에 대해 다음 조건을 모두 확인했다.

```text
p * q == N
(p & MASK) == (P_AND_MASK)
pow(m, 65537, N) == ct
m.hex() == 464c41477b64317274795f6231745f6c33346b5f633070703372736d3174685f6d333374735f73747234743367797d
```

## 참고 자료와 활용

- [Don Coppersmith, *Small solutions to polynomial equations, and low exponent RSA vulnerabilities* (Journal of Cryptology, 1997)](https://research.ibm.com/publications/small-solutions-to-polynomial-equations-and-low-exponent-rsa-vulnerabilities) — `배경지식`에서 작은 modular root를 격자로 정수 근으로 끌어올리고, 알려진 소인수 비트로 RSA를 인수분해할 수 있다는 출발점을 설명하는 데 사용했다.
- [Mathias Herrmann and Alexander May, *Solving Linear Equations Modulo Divisors: On Factoring Given Any Bits* (ASIACRYPT 2008)](https://www.iacr.org/archive/asiacrypt2008/53500412/53500412.pdf) — `256개 edge 후보`와 `이변수 Herrmann--May 격자`에서 미지 블록을 선형식으로 묶고 `y^j f^k N^max(t-k,0)` shift로 삼각 격자를 구성한 직접적인 이론적 근거다.
- [RFC 8017, *PKCS #1: RSA Cryptography Specifications Version 2.2*](https://www.rfc-editor.org/rfc/rfc8017.html#section-5.1) — `복원 결과`와 `검증`에서 사용한 RSA 공개·개인 지수 연산 및 복호화/재암호화 primitive의 기준이며, 이 문제는 별도 padding 없이 raw RSA primitive를 적용한다.
- [FLATTER 공식 프로젝트](https://github.com/keeganryan/flatter) — `이변수 Herrmann--May 격자`와 `격자 공격 재실행`의 171차원 basis 감축, 목표 RHF 옵션 및 빌드 방법을 확인하는 구현 자료로 사용했다.
- [FLINT 공식 `nmod_poly` 문서](https://flintlib.org/doc/nmod_poly.html) — `결과식과 CRT로 근 복원`에서 소수체 위 resultant와 polynomial GCD를 계산하는 API 및 연산 의미를 확인하는 데 사용했다.
