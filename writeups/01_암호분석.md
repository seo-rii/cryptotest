# 1. 암호분석 - 고전 암호

## 문제

두 파일 `ciphertexts1.txt`, `ciphertexts2.txt`는 같은 평문을 서로 다른 고전 암호로 암호화한 결과다. 사용된 암호는 Caesar cipher와 Vigenere cipher이며, 어떤 파일이 어떤 암호인지는 주어지지 않는다.

문제에서 요구하는 작업은 다음과 같다.

- Caesar cipher와 Vigenere cipher의 원리를 설명한다.
- 각 암호문의 Index of Coincidence(IC)를 계산해 암호 종류를 구분한다.
- Caesar 암호문은 카이제곱 검정으로 shift key를 복원한다.
- Vigenere 암호문은 반복 패턴과 부분열 빈도분석으로 key를 복원한다.
- 추가로 주어진 4개 짧은 암호문을 Caesar/Vigenere 관점에서 분류한다.

## 배경지식

### Caesar cipher

Caesar cipher는 알파벳을 고정된 수만큼 평행 이동하는 단일 치환 암호다.

```text
C_i = P_i + k mod 26
P_i = C_i - k mod 26
```

키 공간은 26개뿐이다. 따라서 모든 shift를 시도한 뒤 영어 알파벳 빈도에 가장 가까운 후보를 고르면 쉽게 깨진다.

### Vigenere cipher

Vigenere cipher는 짧은 키워드를 반복해 위치별로 다른 Caesar shift를 적용한다.

```text
C_i = P_i + K_{i mod |K|} mod 26
```

키 길이가 1이면 Caesar cipher와 같고, 키 길이가 길어질수록 전체 암호문의 알파벳 빈도는 평탄해진다. 하지만 키 길이를 알고 나면 같은 key position끼리 모은 부분열은 다시 Caesar cipher가 된다.

### Index of Coincidence

IC는 임의로 고른 두 문자가 같을 확률의 추정값이다.

```text
IC = sum_i n_i(n_i - 1) / (N(N - 1))
```

영어 자연어 또는 단일 치환 암호문은 대략 `0.065` 근처이고, 균등 분포에 가까운 다중 알파벳 암호문은 `1/26 ~= 0.0385`에 가까워진다.

## 풀이

### 1. 파일별 IC 계산

스크립트 실행 결과는 다음과 같다.

```text
ciphertexts1 length=19897 IC=0.067638
ciphertexts2 length=19897 IC=0.043972
```

`ciphertexts1`은 영어 자연어의 불균등한 빈도분포가 거의 보존되어 있으므로 Caesar cipher로 판단한다. `ciphertexts2`는 IC가 낮아 Vigenere cipher로 판단한다.

### 2. Caesar key 복원

모든 shift `0..25`를 시도하고 문제 PDF의 영어 빈도표에 대한 카이제곱 값을 계산했다. 최솟값은 shift `6`이다.

```text
ciphertexts1 is Caesar, shift=6
Caesar plaintext prefix:
THECONSTITUTIONOFTHEREPUBLICOFKOREACHAPTERGENERALPROVISIONS...
```

평문은 대한민국 헌법 영문 텍스트로 시작한다.

### 3. Vigenere key 복원

처음에는 일반적인 Kasiski test와 키 길이별 부분열 카이제곱 검정을 시도할 수 있다. 하지만 이 데이터에는 중요한 구현상 특징이 있다.

`ciphertexts2`는 전체 파일을 하나의 연속 문자열로 암호화한 것이 아니라, 각 줄마다 Vigenere key가 처음부터 다시 적용된다. `ciphertexts1`을 Caesar shift 6으로 복호화해 얻은 줄별 평문과 `ciphertexts2`를 직접 비교하면 key stream은 각 줄마다 다음 패턴으로 반복된다.

```text
KLVOJ
```

즉 실제 암호화는 다음과 같은 형태다.

```text
for each line:
    for i, ch in enumerate(line):
        C[i] = P[i] + "KLVOJ"[i % 5]
```

이 line-reset 특성 때문에 전체 문자열을 그대로 붙여서 키 길이를 추정하면 신호가 흐려진다. 줄 단위 정렬을 보존해야 한다.

### 4. 추가 4개 암호문 분류

추가 암호문 4개는 모두 Caesar-like로 분류된다. 카이제곱 최솟값과 복호화 결과가 자연스럽게 맞는다.

```text
sample 1: Caesar, shift=6
HELLOTHISISACLASSICALCIPHERANALYSISPROBLEMFORTHECRYPTANALYSISCOMPETITIONCONGRATULATIONSONGETTINGTHECORRECTANSWER

sample 2: Caesar, shift=10
HELLOTHISISACLASSICALCIPHERANALYSISPROBLEMFORTHECRYPTANALYSISCOMPETITIONCONGRATULATIONSONGETTINGTHECORRECTANSWER

sample 3: Caesar, shift=10
THANKYOUFORYOURPARTICIPATIONWEWISHYOUALLTHEBESTINYOURFUTUREENDEAVORS

sample 4: Caesar, shift=6
THANKYOUFORYOURPARTICIPATIONWEWISHYOUALLTHEBESTINYOURFUTUREENDEAVORS
```
